# IDW Entertainment Technology

The website for IDW Entertainment Technology, served by GitHub Pages at
[idwent.com](https://idwent.com). It is a single page: `index.html` plus the
images and video in `assets/`.

## Android and Meta Quest

`android/` packages the site as an app that opens with no connection (the
quote form still needs one): one build for Android phones and tablets, and
one that opens as a flat, resizable panel on Meta Quest 2 / 3 / Pro. See
[android/README.md](android/README.md) to build and install. The
**Android APKs** workflow builds both on every push.
